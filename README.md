# Back-End-Development-Pictures
IBM Back-End Application Development Capstone — Pictures Flask microservice.

Run: `pip install -r requirements.txt && python app.py`

Tests: `pytest -q`

The original Coursera screenshots must be captured in the course lab environment; this repository does not fabricate them.

Environment Setup

1. Clone the repository.

2. Create and activate a Python virtual environment.

3. Install the required dependencies using requirements.txt.

4. Run the application.

5. Run the tests using pytest.

Example:

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pytest -v
